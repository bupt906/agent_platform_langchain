# 合规性知识库

## 条目 1：矿山安全生产许可证要求
- 规则：从事矿产资源开采活动，必须依法取得安全生产许可证。未取得安全生产许可证，不得从事生产活动。
- 来源：《安全生产许可证条例》第二条
- 适用场景：矿山开采类文件中对生产许可的表述

## 条目 2：主要负责人安全职责
- 规则：生产经营单位的主要负责人对本单位安全生产工作负有下列职责：建立健全并落实全员安全生产责任制；组织制定并实施安全生产规章制度和操作规程。
- 来源：《安全生产法》第二十一条
- 适用场景：文件中涉及安全管理制度和责任制的内容

## 条目 3：事故隐患排查治理
- 规则：生产经营单位应当建立健全生产安全事故隐患排查治理制度，采取技术、管理措施，及时发现并消除事故隐患。
- 来源：《安全生产法》第四十一条
- 适用场景：安全排查报告、隐患治理方案

## 条目 4：矿山环境保护要求
- 规则：矿山企业应当采取有效措施，防治因开采活动造成的水土流失、植被破坏、地下水破坏等生态环境问题。
- 来源：《矿山地质环境保护规定》第十二条
- 适用场景：矿山开采方案中环境保护措施的描述

## 条目 5：特种作业人员持证上岗
- 规则：矿山井下特种作业人员必须经过专门的安全作业培训，取得相应资格后方可上岗作业。
- 来源：《安全生产法》第三十条
- 适用场景：文件中涉及人员资质要求的内容

## 条目 6：尾矿库安全管理
- 规则：尾矿库应当依法进行安全评价，按照设计要求组织运行，建立安全监测监控系统，实施在线监测。
- 来源：《尾矿库安全监督管理规定》第十九条
- 适用场景：尾矿库相关的运行管理文件

## 条目 7：危险化学品管理
- 规则：矿山企业在生产过程中涉及危险化学品的，应当按照《危险化学品安全管理条例》的规定，取得危险化学品安全使用许可证。
- 来源：《危险化学品安全管理条例》第二十九条
- 适用场景：采矿工艺中涉及危险化学品使用的文件

## 条目 8：劳动防护用品配备
- 规则：生产经营单位必须为从业人员提供符合国家标准或者行业标准的劳动防护用品，并监督、教育从业人员按照使用规则佩戴、使用。
- 来源：《安全生产法》第四十五条
- 适用场景：安全管理制度中劳保用品的规定
