# 用词规范知识库

## 条目 1：禁用"确保安全"空泛表述
- 规则：在安全相关的技术文件中，不得使用"确保安全""保证不出事故"等空泛且无法量化的表述，应代之以具体的量化指标或措施。
- 来源：《矿山安全规程编写规范》第三章（术语与用词）
- 适用场景：安全方案、技术报告中的安全承诺性表述

## 条目 2：危险程度分级用词
- 规则：涉及风险描述时，应使用规范的分级用词——"重大风险 / 较大风险 / 一般风险 / 低风险"，不得使用"有些风险""比较危险"等模糊用语。
- 来源：《企业安全生产风险分级管控体系通则》（GB/T 24353）
- 适用场景：风险评估报告、安全评价文件

## 条目 3：禁止使用绝对化用语
- 规则：技术文件中禁止使用"绝对安全""万无一失""零风险"等绝对化用语，必须使用审慎的概率性表述。
- 来源：行业术语规范——矿山技术文件编写指南
- 适用场景：所有正式技术文档

## 条目 4：设备规格单位规范
- 规则：设备技术参数必须使用法定计量单位（如 MPa、kW、mm），不得使用英制单位或废弃单位。
- 来源：《中华人民共和国计量法》第三条；GB 3100《国际单位制及其应用》
- 适用场景：设备规格说明、招标技术参数

## 条目 5：事故等级分类用词
- 规则：矿山事故等级必须按照"一般事故 / 较大事故 / 重大事故 / 特别重大事故"进行分类，不得简化为"大事故""小事故"。
- 来源：《生产安全事故报告和调查处理条例》第三条
- 适用场景：事故调查报告、预案文件

## 条目 6：禁用威胁性用语
- 规则：在面向公众的通知、告示中，不得使用"违者后果自负""概不负责"等推卸责任或具有威胁性的表达。
- 来源：《公文用语规范》（党政机关公文格式应用指南）
- 适用场景：矿山企业对外公示文件

## 条目 7：人员称谓规范
- 规则：正式文件中应使用法定称谓，如"从业人员""管理人员""特种作业人员"，不得使用"矿工""工头"等非正式称呼。
- 来源：《安全生产法》统一用语规范
- 适用场景：正式的安全管理文件、合同
